# Hollow Knight: Hiori

Protótipo de ação e plataforma 2D.

## Executar localmente

Requisitos: Node.js 22 ou superior.

```bash
npm install
npm run dev
```

## Publicar no GitHub Pages

O projeto está configurado para o endereço:

https://godstudios-web.github.io/hollow-knight-hiori/

O workflow em `.github/workflows/deploy.yml` compila o projeto com Vite e publica automaticamente no GitHub Pages a cada atualização da branch `main`.
